# data/audio

The sound files themselves live under `assets/audio/` (CC0 sounds from Kenney.nl, in the repo
since 2026-07-25; `assets/audio/LICENSE.md`), named by the catalog in `data/sounds.toml`. A sound
the catalog names that is not there yet plays as silence.

This folder holds the loudness data "Even out loudness" (Settings > Audio) plays them by
(docs/design/loudness.md):

- `loudness.toml`, written by hand: each kind of sound (speech, video, music, sound effects,
  ambience, interface, notifications) and the loudness it plays at, which bus is which kind, and
  the limits on raising a quiet sound.
- `measured_loudness.toml`, GENERATED by `just loudness`: how loud each shipped sound file is.
  Run it after adding or replacing a sound file; a lib test fails until you do.
