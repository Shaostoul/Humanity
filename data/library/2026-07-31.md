# 2026-07-31 -- the focus steal falls, foliage becomes leaves, monoliths get a ratchet

## v0.1081.0 / v0.1081.1

### The focus experiment

The operator set up a live experiment: "I'm going to play No Man's Sky...
so you can see when focus is stolen by a subagent without me immediately
clicking back." Foreground tracing during hostile boots (bare exe, detached
spawn, no env var, no marker) produced the discovery of the day: the
v0.1069 create-visible-inactive mechanism NEVER worked. A window created
visible is activated by the system whenever no foreground input lock is
held -- which is precisely when someone is watching a video or playing a
game rather than typing. Every earlier "verified quiet" boot had been
masked by the tester's own keyboard activity.

Fix shipped as BUG-055 (see BUGS.md): policy inversion (focus requires
proof of a human launch: explorer.exe parent or HUMANITY_TAKE_FOCUS from
the operator recipes; dead parent = script = background) + mechanism
(all windows create hidden; background instances shown via raw
SW_SHOWNOACTIVATE at HWND_BOTTOM). New module src/engine/launch_focus.rs,
raw toolhelp32/user32 FFI, no new dependencies. focus_optin_lint pins the
opt-in env var to an allowlist. Final verification: hostile dead-parent
boot with the operator's browser foregrounded, focus-clean across the
whole trace, probe rig still enters the world.

### Vegetation domain pass (wf_11009ff9)

The multi-agent pipeline earned its keep: historian -> fidelity ->
challenger returned ADJUST, stopping the planned atlas work because
fidelity had measured backlit canopies at luma ratio 0.026 vs sky (real
foliage ~0.5) and traced it to a five-line tag bug, not missing cards.
blade() never set Organ::Leaf, so the v0.1078 subsurface transmission and
v0.1080 leaf flutter were dead on 5 of 8 tree species -- the operator's
"one big chlorophyll sheet" report, mechanically explained. Fixed (BUG-056),
runtime-verified in the worktree, critic CONFIRMED with independently
reproduced pixel numbers (0.026 -> 0.448), merged, shipped. The atlas
increment (real impostor tiles for the 6 procedural species) relaunched
as its own domain pass immediately after.

### The monolith ratchet

Operator: "the larger a file becomes the less likely an AI is to
successfully read and modify it." Measurement showed the v0.932-v0.941
extraction arc (lib.rs 22,638 -> 14,937) had regrown 2,740 lines in 140
releases because nothing pushed back. tests/file_size_ratchet.rs now
budgets nine monoliths; growth past budget fails `just lints`, shrinking
600+ under budget demands the budget be lowered. Budgets only go down.
