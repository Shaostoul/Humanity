## Learned

- The light-theme generator's own guard (refuse to run with any colour missing a light value)
  caught the six new section colours the Apps builder added before the light fix landed: a check
  written for one change paid off on the next one within the hour.
- `just lints` built every lint into the same `/tmp/<lint>.test.exe`, shared by every worktree, so
  two sessions running lints at once collided and a lint "failed" with no message. Each run now
  builds into its own folder.
- A release build died inside the compiler with STATUS_STACK_BUFFER_OVERRUN while two other
  builders compiled; retried alone, it built. Two Rust builds at a time is the ceiling on this
  machine.
- The website's copy step has no delete (the web root also holds releases and uploads that no copy
  owns), so a page removed from the repo keeps being served until a line removes it by name. The
  Agents page was deleted from the repo on 2026-08-16 and was still live two months later, linked
  from the mobile menu. `scripts/tests/web-root-retired.test.js` (in `just rig-tests`) now reads
  every page ever removed from `web/` out of git history and fails until the deploy script removes
  it by name, so the next retirement cannot be forgotten.
- The first version of that removal list named a file the site still ships (the Files page's
  upload script, kept from the old Shared Files page under its old name). It survived only because
  the removals run before the copy. A check that a retired file is removed is half a check: the
  test now also fails when a removal matches anything the deploy ships.
- A rig proves only the paths it walks. verify-falls (40/40) walked up the stairs and off the
  top, and never down them, so it passed while walking down the stairs was itself a 3 m fall
  (BUG-208). The builder of an unrelated fix found it by testing the stairs both ways. The rig is
  getting a walk-down leg.
