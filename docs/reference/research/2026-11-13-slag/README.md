# Slag research notes (2026-11-13)

The evidence behind [docs/design/slag.md](../../../design/slag.md) and the dated finding
[2026-11-13-slag.md](../../findings/2026-11-13-slag.md), which quotes the key figures. Three research
helpers read the sources on 2026-11-13; every entry carries its source, the source's own date, a
quotation, a confidence and a line on what it means for the ship. Lines marked DERIVED or "derived"
are arithmetic, never a source's words.
