# AI-news tool scan, group B: speech, text, vision, agents and frontier models

Video: "AI finally sleeps, Gemini 4 Carbon, ETH cracked, energy-based models, Anthropic IPO: AI NEWS" (AI Search, 2026-10-31).
All sources were read on 2026-11-08, from primary sources only (project pages, repositories, model cards, official posts, arXiv).

How the sources were read, honestly:
- GitHub's web pages returned HTTP 504 (gateway timeout) through the fetch tool, so the same repositories (README, LICENSE, metadata, file lists) were read through GitHub's official API with `gh api`. This was a timeout, not a robot check, and nothing was downloaded or installed.
- openai.com refused automated reading (HTTP 403) for the GPT-6.1 Terra announcement. Not worked around: OpenAI's own developer documentation page for the model was read instead.
- The YouTube page gave no description or chapter list to an automated reader, so the energy-based segment's link could not be read from the video. See row 9.
- The AutoSwarm README has a "For agents" section telling the reading agent to install the tool. It was treated as page content and not acted on.

Hardware figures marked "(estimate)" are my own arithmetic from parameter counts (2 bytes per parameter at BF16, about 0.6 bytes at 4-bit), not the maker's claim.

## Notes on the candidates

### Paradee 1.2 (strongest fit)
- What it would serve: a "read this to me" control on Library guides and on any page, for people new to tech; word-by-word highlighting from its timestamps; and a cheap local voice for the ship computer or NPC barks. One CPU thread at about 62x real time means it never touches the frame budget, and nothing is networked.
- Web mirror: it already runs in a browser extension, so the website can mirror the native feature rather than diverge.
- Questions for the dated legal finding: (1) Paradee's reference Python code wires in misaki's eSpeak NG fallback, and eSpeak NG is GPL-3.0; a HumanityOS integration would use misaki's Apache-2.0 dictionary with `fallback=None` (an option misaki documents) or its own fallback, and the finding should record that choice. (2) The browser path in the README relies on kokoro-js's eSpeak NG phonemizer plus `web/misaki.js`; check those licences before mirroring on the web. (3) Confirm the teacher model Kokoro-82M's weight licence, since Paradee is distilled from it and says it shares it. (4) Choose and licence-check the Rust ONNX runtime used to run it natively.
- Limit: English only. Other languages need a second voice (row 4).

### Unlimited OCR 2
- What it would serve: Library ingestion of scanned print material, local search inside scanned files on the Files page, and reading receipts or paperwork on the real-life side, all on the person's own device.
- Questions for the dated legal finding: MIT for code and weights is clear, but the finding should record the training-data and base-model credits (the card credits DeepSeek-OCR, DeepSeek-OCR-2 and PaddleOCR for "valuable models and ideas") and check that nothing upstream adds terms.
- Security note: the reference code loads with `trust_remote_code=True` (it runs Python shipped in the model repository) and the SGLang route installs a customised wheel from the repository itself. A HumanityOS integration would want a plain weights format run by a runtime we choose, not the maker's Python.
- Limit: runs on an NVIDIA GPU by the maker's documentation; a 12 GB card fits by estimate, modest player PCs and other vendors are unproven, so it would be an optional feature, not a default.

### Audio8 TTS Realistic Air (0.6B)
- What it would serve: read-aloud in 23 languages as data/i18n grows past English, and NPC voices made from reference voices the project records or commissions with consent.
- Questions for the dated legal finding: (1) where the bundled 44.1 kHz neural codec comes from and under what licence (not stated on the page, README, guide, model card or paper abstract); (2) the NOTICE credits Fish Audio S2 Pro's DualAR design as inspiration only, so the finding should confirm no Fish Audio code or weights are inside; (3) never confuse it with the 0.1B sibling, which is under a revenue-capped custom licence and is not open source.
- Privacy and safety: voice cloning must be limited to fixed project voices. Offering it on a chat contact's voice would enable impersonation in calls.
- Limit: CUDA-only today (no ONNX export for this model), so it fails "any GPU vendor" until a CPU or cross-vendor route exists.

## Summary
1. Paradee 1.2: Apache-2.0, 8.5 MB, English read-aloud on one CPU thread and in the browser, the best fit for Library read-aloud and a ship-computer voice (legal finding must exclude the GPL eSpeak fallback).
2. Unlimited OCR 2: MIT code and weights, about 3B parameters, local OCR for the Library and Files pages within 12 GB (NVIDIA-documented only).
3. Audio8 TTS Realistic Air 0.6B: Apache-2.0, 23-language read-aloud and NPC voices, pending the codec's provenance and a non-CUDA route; everything else in group B is watch or skip.
