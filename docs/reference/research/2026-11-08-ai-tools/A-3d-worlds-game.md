(AI Search, 2026-10-31). Operator's request, 2026-11-08: "review all the new AI tools showcased on this video".

**How this was read (2026-11-08).** Primary sources only, all read on 2026-11-08: each project page linked from
the video's description, the project's GitHub repository (README and licence, read through the GitHub API after
two repository web pages returned HTTP 504), its Hugging Face model or dataset card and the card's metadata, and
the arXiv record. Automated reads identified themselves as a research tool; no site refused or showed a robot
check. Nothing was downloaded or installed (one SimReady asset's `LICENSE.txt` and one MDL file's header were
read as text). MotionBricks was skipped as the brief says. Release dates are the earliest primary date found
(arXiv v1, repository or weights creation, or the post's own date).

## Notes on the candidates

### NVIDIA SimReady Assets (candidate)

- **Why:** real-world objects modelled at real scale for industrial digital twins, with physics data. That is the
  realistic-first standard ("build the 2030 version"), and it is openly licensed data rather than a tool.
- **What the dated finding must settle:**
  - the dataset card's `cc-by-4.0` against each chosen asset's own `.metadata/LICENSE.txt` (one asset was checked,
    `appliance_toaster_a01`: the full CC BY 4.0 text). Check every asset that is actually used, not a sample.
  - the bundled `.mdl` files' NVIDIA BSD-style header (the engine would likely drop MDL and keep only the PNG maps).
  - how attribution is shown: `CREDITS.md`, and in the app where the object appears.
    `docs/reference/findings/2026-10-12-media-item-licences.md` (section 1.2) already sets out what CC BY requires.
  - that the finding covers only this NVIDIA dataset: other "SimReady Central" datasets come from other
    contributors and may carry different terms.
- **Engineering:** 490 GB in total, so pick assets by folder. Convert USD to `.glb` offline with a dev script whose
  output goes under `assets/art/models/` (per `docs/design/asset_rules.md`). The texture set is albedo, normal and
  ORM PNGs, which map onto the engine's metallic-roughness PBR. Physics payloads (PhysX, Newton, MuJoCo) can seed
  mass and collider rows in a data file (infinite-of-X), not in code. The library leans hospital and industrial,
  so check fit room by room (kitchen, life support, a medical area).

### IDOL (candidate, conditional)

- **Why:** a local photo-to-3D tool that fits the operator's 12 GB card ("7.2 GB of VRAM" peak). The photo never
  leaves the device, which fits privacy-first.
- **What the dated finding must settle:**
  - IDOL itself is Apache-2.0 (code and weights), but it loads DINOv3 under Meta's "DINOv3 License" (custom, not
    OSI; redistribution only under the same terms; Trade Control and military-use exclusions; access granted by
    hand) and the FLUX.2-dev VAE under `flux-non-commercial-license`. The finding must say whether using that VAE as
    an encoder, and shipping assets made with it, is allowed.
  - Black Forest Labs' FLUX.2-klein-4B is `apache-2.0` and has its own `vae` folder. Whether that VAE is the same
    as the FLUX.2-dev one IDOL loads is **unverified**; check it by checksum, not assumption, before treating it as
    a swap.
- **Engineering:** HumanityOS has no Gaussian-splat path. A wgpu splat pass (sorting cost against the frame budget)
  or a splat-to-mesh conversion would have to come first. It is NVIDIA-only ("an NVIDIA GPU with CUDA"), so it would
  be an authoring tool for the operator, not a player feature on AMD, Intel or modest PCs.

## The best of the rest

- **PhysAg3D (watch):** the closest match to "interactive homestead machines" (a GLB with joints, tested in MuJoCo).
  It is held back by its closed agent (Codex CLI with a ChatGPT login) and a 28 GiB GPU. Worth re-checking if it
  gains a local open model backend.
- **StreamVibe (watch):** a proactive helper that speaks only when useful fits the ELI5 mandate. Re-check when the
  code and weights appear, for the licence and the model size; it is acceptable only if it runs fully on-device.
- **Negative findings worth keeping:** the MiniMax H3 Community License (behind Open-H3-Regenerate-2K and, through
  its finetune, likely MUNDO) excludes the United States. MatAnyone-E is non-commercial (S-Lab License 1.0).
  SceneBloom's image stage is non-commercial FLUX.1 [dev].

## Three-line summary

1. NVIDIA SimReady Assets (candidate): 2,677 real-scale CC BY 4.0 props with physics data, for homestead kitchens, life support and a medical area. It needs an offline USD-to-glTF step and an attribution finding.
2. IDOL (candidate, conditional): an Apache-2.0 photo-to-3D-splat model that fits the RTX 4070 (7.2 GB), but it loads non-open DINOv3 and FLUX.2-dev VAE weights, and the engine has no splat renderer yet.
3. Watch PhysAg3D (image to a jointed, physics-tested GLB, but it needs ChatGPT/Codex and a 28 GiB GPU) and StreamVibe (a proactive on-device helper, not released). Skip Genie 4, MUNDO, OverSeer, UniAction and Open-H3-Regenerate-2K, whose weight licence excludes the United States.
