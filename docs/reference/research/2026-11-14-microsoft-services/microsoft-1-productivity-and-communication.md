# Microsoft's productivity and communication services: an inventory

What this file is: a list of the productivity and communication services Microsoft offers to people
and organisations (mail, calendars, calls, chat, files, documents, notes, tasks, video, plans), what
each is for in everyday words, the abilities people rely on, which free tier or plan it comes in, and
one short quotation from Microsoft's own pages. It is research for the question of what HumanityOS is
still missing; it says nothing about what we should build.

Read on 14 November 2026 (Pacific).

Method:
- Readers: `curl -A "Claude-User (research tool)"` (an honest identity) with the page text extracted
  by a small script, and WebFetch. Each host's robots.txt was read first, in a step of its own.
- www.microsoft.com refused every product page (see "Could not read"), so every fact below comes from
  Microsoft's own help sites, support.microsoft.com and learn.microsoft.com, which are Microsoft's
  primary pages too. A web search was used only to find the addresses of those pages, never as a source.
- "Page date" is the date in the page's own metadata (`ms.date`), which these two sites show as the
  article's date. Where it looks stale it is marked so.
- Quotations are exact (curly quotes normalised to straight). Where a quotation is part of a sentence,
  it is still the page's exact words.

Words used below: a "tenant" is one organisation's private space in Microsoft's cloud; "PSTN" is the
ordinary public telephone network (landlines and mobile numbers); a "plan" is a paid subscription.
