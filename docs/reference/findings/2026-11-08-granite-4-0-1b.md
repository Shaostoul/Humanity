# Granite 4.0 1B: may the project serve its GGUF as the low-memory NPC brain

**Research date: 8 November 2026** (Pacific time). Every source below was read that day by an AI
research agent working for the project, identifying itself in every request as
"HumanityOS-research-agent/1.0 (automated AI research tool ...)". Hugging Face pages were read
through the public model API and raw file pages, GitHub through its API and
raw.githubusercontent.com, IBM's site as a page. Nothing was downloaded, installed or run. Each
source carries its own date where it shows one.

**I am not a lawyer, and this is not legal advice.** It is a reading of public licences, model cards
and disclosures, written so a later reader can check every word against the same sources.

Builds on the 2026-11-08 NPC brain and voice scan,
[`../research/2026-11-08-npc-brain-voice/README.md`](../research/2026-11-08-npc-brain-voice/README.md),
which named this model the low-memory fallback for 8 GB PCs and asked for this finding (Part 3,
"Dated legal findings still needed", item 2).

## The question

May HumanityOS serve IBM's Granite 4.0 1B as a GGUF file from its own release downloads and run it
on the player's machine through llama.cpp for NPC dialogue and the in-app helper, and does any base
model, dataset, usage text or other term add to its Apache 2.0 licence?

## Short answer

- **ALLOWED: redistributing the GGUF and running it for NPC lines and the helper.** Apache 2.0 is
  stated on the instruct, base and GGUF cards, and IBM's GitHub repository for the model family holds
  the unaltered Apache 2.0 text as its `LICENSE` (F1).
- **The base model is IBM's own**, trained from scratch, also Apache 2.0 (F2).
- **IBM publishes its training datasets**: a machine-readable disclosure, dated 30 March 2026, lists
  131 pre-training and 115 post-training dataset entries for this exact model, every one marked
  `"user_data": "no"` (F3). It names sources but gives no licence per dataset.
- **One extra sentence lives on IBM's Granite web page, not in the licence**: "All IBM Granite model
  users may not use, or allow others to use, IBM Granite models to engage in or facilitate any action
  to generate output that infringes, misappropriates, or otherwise violates any third-party copyright
  rights." It sits in a section about watsonx indemnification and restates the law (F4).
- **No NOTICE file** anywhere, and the `LICENSE` appendix is unfilled, so there is no copyright line
  to retain; the project ships the Apache 2.0 text (F1, F5).
- **The file**: IBM's own `granite-4.0-1b-Q4_K_M.gguf`, 1,023,645,440 bytes (F5).
- **UNCLEAR**: the licence of each disclosed dataset (not listed), and IBM's "Responsible Use
  Guide" PDF, whose link redirected to IBM's Granite page and could not be read (F3, F4).
- **Recommendation: yes**, as the fallback for low-memory PCs, on the conditions below.

## Findings

### F1. The licence as stated, and the file itself

- **Instruct model card**, https://huggingface.co/ibm-granite/granite-4.0-1b (repository created
  2025-10-07, last modified 2025-10-23, not gated). Metadata `license: apache-2.0`,
  `base_model: ibm-granite/granite-4.0-1b-base`. Its header:
  > - **Release Date**: October 28, 2025
  > - **License:** [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)
- **IBM's GitHub repository for the family**, https://github.com/ibm-granite/granite-4.0-nano-language-models
  (created 2025-10-09, last push 2026-03-30; GitHub's licence detection: Apache-2.0). README:
  > All models are publicly released under the Apache 2.0 license, allowing free use for both research and commercial purposes.

  and its "License" section:
  > All Granite 4.0 Nano Language Models are distributed under Apache 2.0 license.

  (As rendered; in the source, "Apache 2.0" links to the repository's `LICENSE` file.)

  Its `LICENSE` is the unaltered Apache License 2.0 text, the appendix left as the placeholder
  `Copyright [yyyy] [name of copyright owner]` (compared line by line with apache.org's copy; the
  only difference is a leading blank line).
- The Hugging Face repositories hold no `LICENSE` file (instruct: 12 files; base: 11; GGUF: 17,
  listed through the API). Apache 2.0's section 4(a) still asks the project to hand the licence to
  recipients:
  > (a) You must give any other recipients of the Work or Derivative Works a copy of this License; and

### F2. The base model: IBM's own, trained from scratch

- **Base card**, https://huggingface.co/ibm-granite/granite-4.0-1b-base (created 2025-10-07, last
  modified 2026-06-12, not gated): `license: apache-2.0`, no `base_model`. It says:
  > The model is trained from scratch on approximately 15 trillion tokens following a four-stage training strategy: 10 trillion tokens in the first stage, 2 trillion in the second, another 2 trillion in the third, and 0.5 trillion in the final stage.

  and under "Training Data":
  > This model is trained on a mix of open source and proprietary data following a four-stage training strategy.
- **The instruct card** on its own tuning:
  > Granite-4.0-1B is a lightweight instruct model finetuned from *Granite-4.0-1B-Base* using a combination of open source instruction datasets with permissive license and internally collected synthetic datasets.

  and under "Training Data":
  > Overall, our SFT data is largely comprised of three key sources: (1) publicly available datasets with permissive license, (2) internal synthetic data targeting specific capabilities, and (3) a select set of human-curated data.

### F3. IBM's dataset disclosure for this model

- **The disclosure file**, https://github.com/ibm-granite/granite-4.0-nano-language-models/blob/main/disclosures/granite_4.0_1b_disclosure.json
  (its own `"timestamp": "2026-03-30T14:53:27Z"`; model `"name": "Granite-4.0-1b"`). Its disclaimer
  opens:
  > Structured dataset metadata used for pre- and post-training IBM Granite 4 base and instruct models is being released as part of IBM's effort to provide the community with highly transparent open source model development.
- **What it lists** (counted by a script on the research date): 131 pre-training entries (87 under
  "pre-training", the rest under web, code, domain, academic, technical, math, multilingual and
  others) and 115 post-training entries. Each entry has a name, a URL where public, a date obtained,
  a description, a size, languages, a "source" ("IBM" or "third party"), a "data_provenance", and
  flags for synthetic and seed data. **Every entry has `"user_data": "no"`.** There is **no licence
  field** per dataset. The first entry is GneissWeb (source "IBM", "Web crawling", "around 10
  trillion tokens"); third-party entries include "Webhose" ("Unstructured web content in English
  converted into machine-readable data feeds acquired by IBM"), Free Law, USPTO patents and SEC
  filings. Pre-training lists 59 IBM and 72 third-party entries; post-training 59 IBM and 56
  third-party.
- **The disclosures' own licence**, `disclosures/README.md`:
  > All Granite 4 disclosures are distributed under CDLA Permissive V2 licenses.

### F4. IBM's other texts: a sentence on the Granite page, and a guide that could not be read

- **IBM's Granite page**, https://www.ibm.com/granite (page data: published 2025-07-10, modified
  2026-10-06). In a section on IBM's contractual indemnification for watsonx customers it lists
  "(2) Granite family of a decoder-only model" among "The current watsonx models now under these
  protections", and then says:
  > All IBM Granite model users may not use, or allow others to use, IBM Granite models to engage in or facilitate any action to generate output that infringes, misappropriates, or otherwise violates any third-party copyright rights.

  The same page's footnote:
  > As of 29 April 2026, released Granite language, vision, speech, embedding and guardian models are being cryptographically signed.

  (The instruct and base repositories hold a `model.sig` file; the GGUF repository does not.)
- **The sentence is not in the Apache 2.0 text**, no card links to it, and no gate asks anyone to
  accept it. The indemnity around it is "contractual" and offered to IBM's customers, which the
  project is not.
- **IBM's "Responsible Use Guide"**, which the disclosure's disclaimer cites at
  https://www.ibm.com/granite/docs/resources/responsible-use-guide.pdf: the address answered with a
  301 redirect to https://www.ibm.com/granite, so the guide itself could not be read (below).
- **The instruct card's "Ethical Considerations and Limitations"** is advice, not a term:
  > So we urge the community to use this model with proper safety testing and tuning tailored for their specific tasks.

### F5. The GGUF file

- **IBM's own GGUF repository**, https://huggingface.co/ibm-granite/granite-4.0-1b-GGUF (created
  2025-10-23, last modified 2026-04-23, not gated): `license: apache-2.0`,
  `base_model: ibm-granite/granite-4.0-1b`. Its card:
  > This repository contains models that have been converted to the GGUF format with various quantizations from an IBM Granite base model.

  and a technical note (not legal):
  > This model often uses the full numerical range of a 32-bit float (`f32`), so variants with smaller numerical ranges may run into precision errors at inference. The `F16` variant is known to fail on many hardware combinations.
- **The file** `granite-4.0-1b-Q4_K_M.gguf`: 1,023,645,440 bytes, LFS object id
  `22ec0f9cc99a90185312de3c882c84e7bd6789bdd050389844380a01a831d7f1` (API tree, research date).
- **No NOTICE file** in any of the three Hugging Face repositories or the GitHub repository (whose
  tree holds `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `LICENSE`, `README.md`, the disclosures and two
  images). Apache 2.0's section 4(d) therefore asks nothing. Apache 2.0 calls a converted file
  "Object" form, defined as including "conversions to other media types", so the GGUF is the same
  Work under the same licence.

## What it means for this project

### Certain

- The project may publish `granite-4.0-1b-Q4_K_M.gguf` as a release asset, or inside a release, and
  have the app fetch and run it for NPC dialogue and the helper, provided each copy travels with the
  Apache 2.0 text (F1, F5).
- No licence term limits what the model may be used for or claims anything over its output (F1, F4).
  Players are bound by nothing from the model's side.
- The model's family has no outside base model (F2).

### Judgement calls

- **IBM's web-page sentence (F4) costs nothing to honour**: NPC lines are not an attempt to
  reproduce anyone's copyrighted text. It is not a licence condition and does not pass to players.
- **The disclosure is a real advantage** over the other candidates for a project that tells people
  where things come from: the training sources are listed and none is marked as user data (F3).
- **Serve IBM's own GGUF, pinned by its hash**, from the project's release assets (the same reasons
  as the Ministral and Spark findings).
- **Label it as AI wherever it speaks**, and write the project's own system prompt.

### How the project would credit it

- **Beside the model file**: `LICENSE` (the Apache 2.0 text, as in IBM's repository) and a short
  `README.md`: "Granite 4.0 1B (Q4_K_M GGUF) by IBM, https://huggingface.co/ibm-granite/granite-4.0-1b-GGUF,
  Apache License 2.0. Unmodified. Training data disclosure:
  https://github.com/ibm-granite/granite-4.0-nano-language-models/tree/main/disclosures."
- **`data/credits.ron`**, `CREDITS.md` and `LICENSES.md`: one row and section, as for Ministral.
- **The download screen**: name, size (1.02 GB), maker, licence, before the person agrees.

### The question for the operator

**May Granite 4.0 1B (Apache 2.0, IBM's own model with a published dataset list) be the NPC brain
for PCs with too little memory for Ministral 3 3B?**

Recommendation: **yes.** Its licence is the plainest of the candidates and its training sources are
the best documented after OLMo. Conditions: IBM's own Q4_K_M GGUF pinned by hash and served from the
project's release assets, the Apache 2.0 text and credit beside it, the project's own system prompt,
an "AI" label wherever it speaks, and the rig test passed.
