# HumanityOS (HOS)

**We are building a game + toolset to help people become more capable, together.**

---

## Explain Like I'm 5

Imagine the world is a giant spaceship.

- Some people know how to grow food.
- Some know how to fix machines.
- Some know how to teach.
- Some know how to organize.

If we share these skills, everyone does better.

**That is our mission:**
Help people learn useful life skills, cooperate at scale, and build systems that reduce suffering.

Not by handouts forever.
By making capability easy to learn and use.

---

## What We're Trying to Accomplish for Humanity

1. **Teach practical skills** (food, building, systems, teamwork)
2. **Make collaboration simple** (chat, shared planning, shared knowledge)
3. **Build resilient communities** (local + global, online + offline)
4. **Prepare for long-term civilization growth** (Earth first, then beyond)

---

## Where the Project Is Headed

One app, two sides of the same tools, switched with a **Real/Sim toggle**:

- **Real**, life tools you actually use: chat, inventory, tasks, maps, market, notes, health
- **Sim**, a full 3D game teaching the same skills: homesteading, farming, construction, off-grid systems, on a true-scale Earth and beyond
- **The native desktop app is the product**; the website mirrors it so everything works in a browser too
- **Federated and self-hostable**, anyone can run a server; your identity travels with you

## Live Now: HumanityOS

**[united-humanity.us/chat](https://united-humanity.us/chat)** (web) · **[Desktop app](https://github.com/Shaostoul/Humanity/releases/latest)** (the full experience)

Current platform includes:

- Real-time chat, voice/video calls, and collaboration
- Post-quantum cryptographic identity (no accounts, no password trap)
- A 3D world with a true-scale Earth: live weather, oceans, atmosphere, day/night
- Farming, crafting, construction, and skills gameplay
- Tasks, inventory, marketplace, maps, and a knowledge library, in-app and on the web

## Why This Exists

Poverty is not only about money.
It is also about missing skills, missing tools, and missing support.

So we build:

- open systems,
- open knowledge,
- practical learning paths,
- and shared infrastructure.

Everything is aimed at helping people become capable of helping themselves and each other.

---

## The Simulation (born as Project Universe)

The game layer, started in 2019 as Project Universe and now the Sim side of HumanityOS:

- players as crew in humanity's first interstellar fleet,
- non-combat systems first,
- real-world skill transfer through gameplay,
- deep cooperation through infrastructure and missions.
