# 2026-09-30

Continues the session of 2026-09-29 (`docs/history/2026-09-29.md`).

## Shipped

- **Marketing, with evidence first.** The operator asked why update posts
  do poorly. Two days of server logs: about 19 visitors from social links,
  about 450 homepage loads and about 30 who went further. The diagnosis:
  changelogs only reach people who already care, text-only posts are shown
  to fewer people, and the page loses most arrivals. Video was the lever
  the operator chose.

- **v0.1435.0: the clip maker.** `just clips` films the
  game for social media: the engine's new movie mode locks each frame to
  1/fps, slides the animation clock (`start_time`) to match, steers the
  camera (hold, pan, a Catmull-Rom dolly through the home, an exponential
  drop from orbit) and pipes every frame into ffmpeg; the script cuts
  16:9, 9:16 and a still per shot, with suggested captions. First test:
  300 and 360 frames at 2560x1387 in under 30 s each, no repeated frames.
  The first run sat silent for four minutes because the rig had no DXC
  compiler DLLs (they live in the repo root, not beside target/release).

- **v0.1435.2: the web chat works on older phones (BUG-106).** A user
  in Nigeria could not connect: "Post-quantum identity could not be
  initialized". The identity seed lived only inside a WebCrypto Ed25519
  key, which Chrome enables by default only from version 137 (2025); every
  older Chrome got a key with no private half. The seed is now held
  directly there, in the same backup format, so an updated browser keeps
  the same identity. Proven in the browser pane with Ed25519 switched off:
  connect, update, recovery phrase and backup file all keep one identity.
  Importing any backup made since the PQ cutover had been failing too; it
  works now.

## Learned

- Look at every clip before calling it made. The first full batch was 7/7
  "ok" and five of them were unusable: Earth never turned, the sunset never
  set, the drop ended inside the ground, Silverdale was grey haze. A green
  exit code measured that ffmpeg wrote a file, not that the file shows
  anything.
- `time_scale` is game seconds per real second, and the normal game runs
  at about 72 (a 20-minute day). "12" for a time-lapse SLOWED the clock.
  A sunset over 12 s wants about 330; Earth turning an eighth wants 900.
- Somewhere between 300 and 1,500 km up the frame lock releases Earth ("left its envelope"),
  and the rig descent needs the lock, so a drop starts at 300 km. The
  stopping height has to be over the DRAWN ground: over the sphere, the
  first drop at Fuji finished underground.
