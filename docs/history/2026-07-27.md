## v0.1001.0 + v0.1002.0 - terrain draw batching (the approved proper fix)

Full design: docs/design/terrain-draw-batching.md. Short version:

Increment 1: every terrain patch used to be its own RenderObject with its
own GPU buffers - at the operator's 12,288 budget that meant ~50k
render-pass commands and two 3 MB uniform staging uploads per frame. Now
all patches live in one range-allocated mega vertex/index buffer pair
(patch streaming creates ZERO GPU buffers), per-patch data rides an
instance record, the megashader gained accessor-routed object sourcing
with a marker-substituted batch variant (6 PSOs, hot-reload covers both),
and the cache LRU finally accounts REAL bytes instead of the flat 38 KB
estimate. Graceful degradation: arena-full falls back to the classic
per-patch path, logged, never a crash.

Increment 2: the A/B isolated a cost scaling with draw count, so the
per-patch data moved to an instance-rate VERTEX ATTRIBUTE (the
instance_index builtin is broken for indirect draws on this DX12 adapter -
missing downlevel flag - while attribute fetch honors first_instance in
hardware everywhere) and the whole batch now submits as ONE
multi_draw_indexed_indirect when the device grants MULTI_DRAW_INDIRECT +
INDIRECT_FIRST_INSTANCE (requested as the adapter intersection, so the
request can never fail a boot; this RTX 4070 grants both).

THE HONEST MEASUREMENT: after increment 2, frame time at 8,712 batched
patches was ~25 ms vs ~26 ms before - near parity. That parity IS the
finding: with submission down to one command, the 12k-budget frame is GPU
vertex-throughput-bound (~9.2M unshared flat-shaded vertices, zero
post-transform cache reuse), not submission-bound. The CPU-side win
(staging, bind churn, ~25k matrix inversions per frame) is real and helps
the operator's loaded session most; the next big lever is a separate arc:
shared terrain vertices with FS-derived per-face data, or bigger patches
(PATCH_TESS 16 -> 32 = quarter the draws at equal quality).

Verification: 1167 lib tests, 5 new allocator tests (churn-never-leaks
property among them), both shader variants naga-validated, release exes
boot-verified (0 panics), visual identity confirmed through the new path
at desert + tropical forest vantages, [PatchBatch] diag shows 8,712
batched / 0 fallback.

## v0.1003.0 - cloud self-shadowing (post-wrap bonus increment)

"Clouds don't block light from each other" turned out to be a BUG, not a
missing feature. Method worth keeping: a TEMPORARY tau heat-map written
into the cloud shader and hot-reloaded on the running rig turned each
hypothesis into a minutes-long falsifiable experiment. The probe showed
sun-shadow optical depth was ~0.1 across a SOLID NOON OVERCAST: the light
march reused the view-calibrated extinction (kept low so deck edges
feather), structurally capping every shadow at ~e^-0.5, and its first tap
jumped ~15% of the slab, overshooting thin stratus bands completely.

Fix: the standard view/light extinction split (CLOUD_LIGHT_SIGMA_MULT 6.0
in cloud_sun_tau only; the multi-scatter octaves keep deep shadows
luminous) plus the base light step halved. Mirror constants + the
lockstep table updated; 24/24 cloud tests. Rig before/after at the same
surface look-up: featureless bright whiteout in the morning, real gray
overcast underside with bright thin patches after. Deck tops at high sun
stay bright and near-flat, which is physically right.

Also corrected the v0.1000.0 record: the height squash lives in the
Medium/Low density path; High-tier height shaping is cloud_carve's own
towering (the mesoscale-cells improvement on High was real either way,
cloud_field is shared by all tiers).

## v0.1014.1 - clouds field report: domes, turrets, and the straight-line hunt

Operator field report with two real-photo references: bulky cloud edges
read as cliffs, tops read as one flat sheet from above, and hard
straight-line artifacts get worse approaching the layer. All three
root-caused and fixed in one arc, rig-verified before/after at a broken
deck off the Libyan coast (weather-data scan found the vantage: mid
fraction, all-valid, local noon).

1. Cliffs + flat sheet were the same bug: the carve threshold was
   CONSTANT with height, so any shape cell that existed at all existed at
   full band height under one shared ceiling. Now the threshold RISES
   quadratically with band fraction (CLOUD_TOP_RISE 0.45): each ~45 km
   cell domes at its own height, bases stay broad and flat. The light
   march shares cloud_carve, so inter-dome valleys catch real shadow.
2. The from-above sheet ALSO had a lighting cause: the light-march's
   first tap was ~3.9 km, so every near-top sample saw tau 0 - the deck
   top was lit dead flat no matter its relief. The ladder is now
   GEOMETRIC (first tap ~0.9 km, x1.8 per tap, ~125 km reach, same 8
   taps), plus a crown channel out of cloud_carve (how close a sample is
   to its own column's domed top) drives valley shade / crown light that
   survives even a zenith sun, and crown-weighted fine erosion breaks
   crowns into 3-13 km turrets (the reference photos' castellation).
3. The straight lines were TWO artifacts: (a) the FINE erosion band still
   sampled the east-west-stretched noise domain (same bug class as the
   v0.1012 puff-lance fix; fades in within ~190 km - exactly "worse the
   closer I get"); now both isotropic erosion bands sample the
   drifted-but-unstretched domain, only fray + filaments keep the
   mares'-tail stretch. (b) The live MODIS composite itself: adjacent
   swaths captured hours apart meet in RULER-STRAIGHT fraction steps
   (data scan confirmed hard N-S lines at lon ~125E + the date-line
   seam), and the single [1,2,1] blur left ~2-texel steps the coverage
   smoothstep re-sharpened. Fraction blur widened to 3 passes (~130 km
   fronts), and the validity channel is now a chamfer-distance FEATHER
   (~500 km live/procedural crossfade, idempotent, also applied to
   pre-v0.1014 caches at load) instead of a binary flip inside one
   bilinear texel. Razor swath band at (12N 122E): gone in the A/B.

Also: CLOUD_COV_SOFT 0.20 -> 0.28 (knife-taper snouts feather out), and
the whole session's shader work hot-reloaded into the operator's live
game as it landed. 5 new live_weather tests (feather ramp, antimeridian
wrap, no-op on full-valid); 24/24 cloud tests; relay check clean.
