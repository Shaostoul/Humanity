## v0.1001.0 + v0.1002.0 - terrain draw batching (the approved proper fix)

Full design: docs/design/terrain-draw-batching.md. Short version:

Increment 1: every terrain patch used to be its own RenderObject with its
own GPU buffers - at the operator's 12,288 budget that meant ~50k
render-pass commands and two 3 MB uniform staging uploads per frame. Now
all patches live in one range-allocated mega vertex/index buffer pair
(patch streaming creates ZERO GPU buffers), per-patch data rides an
instance record, the megashader gained accessor-routed object sourcing
with a marker-substituted batch variant (6 PSOs, hot-reload covers both),
and the cache LRU finally accounts REAL bytes instead of the flat 38 KB
estimate. Graceful degradation: arena-full falls back to the classic
per-patch path, logged, never a crash.

Increment 2: the A/B isolated a cost scaling with draw count, so the
per-patch data moved to an instance-rate VERTEX ATTRIBUTE (the
instance_index builtin is broken for indirect draws on this DX12 adapter -
missing downlevel flag - while attribute fetch honors first_instance in
hardware everywhere) and the whole batch now submits as ONE
multi_draw_indexed_indirect when the device grants MULTI_DRAW_INDIRECT +
INDIRECT_FIRST_INSTANCE (requested as the adapter intersection, so the
request can never fail a boot; this RTX 4070 grants both).

THE HONEST MEASUREMENT: after increment 2, frame time at 8,712 batched
patches was ~25 ms vs ~26 ms before - near parity. That parity IS the
finding: with submission down to one command, the 12k-budget frame is GPU
vertex-throughput-bound (~9.2M unshared flat-shaded vertices, zero
post-transform cache reuse), not submission-bound. The CPU-side win
(staging, bind churn, ~25k matrix inversions per frame) is real and helps
the operator's loaded session most; the next big lever is a separate arc:
shared terrain vertices with FS-derived per-face data, or bigger patches
(PATCH_TESS 16 -> 32 = quarter the draws at equal quality).

Verification: 1167 lib tests, 5 new allocator tests (churn-never-leaks
property among them), both shader variants naga-validated, release exes
boot-verified (0 panics), visual identity confirmed through the new path
at desert + tropical forest vantages, [PatchBatch] diag shows 8,712
batched / 0 fallback.
