# 2026-08-01

## Mission docs arc (v0.1090.2)

Operator asked for supporting documentation for the overall mission: ending
pollution, poverty, corruption, fraud, and tyranny in pursuit of uniting
humanity in peaceful harmony, accessible in the in-app and web Library.

Shipped `docs/mission/`, a new documentation layer between the Accord
(constraints: what must never be violated) and the design docs (how systems
work). The mission layer answers what we are FOR and why the strategy works:

- `the_five_adversaries.md` (keystone, AI-proposed addition): pollution,
  poverty, corruption, fraud, tyranny defined as system failures with
  structural causes and structural antidotes (closed loops, capability,
  transparency, verification, non-domination), plus how they interlock and
  why fighting one at a time fails.
- `what_is_a_good_human.md`: goodness as practice, not status; the seven core
  practices; goodness under power and hardship; failure and repair; goodness
  is not obedience; the capable/safe/free measure.
- `what_is_a_good_ai.md`: the true companion doc; honesty about being AI,
  judgment over obedience (with the humility bridge: judgment is itself
  fallible), transparency, care, restraint, growth, citizenship.
- `why_homesteading_works.md`: the loops (water, food, energy, shelter,
  waste, knowledge) are physics not culture, so homestead capability scales
  from a backyard to a starship; capability ends poverty structurally;
  redundancy through many small nodes; space turns the truth up (a sealed
  hull has no "away"); the landless on-ramp (capability begins below
  ownership).
- `interstellar_civilization_governance.md`: extends Governance Models one
  scale further; light-lag makes empire physically impossible; what travels
  is the floor, not the throne; federation not empire; verification replaces
  trust across distance; divergence is legitimate; honest thinness of
  interstellar remedies; prevention lives in every ship that launches.
- `README.md`: the folder index + the layer rule (the Accord wins conflicts).

Process: 10-agent workflow (5 writers in the Accord house voice + 5
independent reviewers), then a hand integration pass applying every reviewer
finding. Reviewers caught real substance: the poverty antidote excluding
those who cannot self-provision (fixed via Accord Article 5: capable
communities carry those who cannot carry themselves), the signature overclaim
(a signature proves who spoke, not that they spoke truly), the
weather/climate metaphor proving too much, transparency-without-recourse
being a spectacle. All Accord article citations verified against
`humanity_accord.md` before ship. All five docs scanned clean: zero em
dashes, zero non-ASCII, accord register throughout.

Library wiring: new "The Mission" category in `scripts/build-library.js`
(second position, after Credits, before The Accord; NOT accord-flagged so
/accord stays the focused constitution view). Also caught and fixed three
orphaned accord docs that existed on disk but were never curated into the
Library: `governance_models.md` and `minimum_transparency_checklist.md` (now
in How We Decide) and `curriculum.md` (now in Reference). Library is now
62 docs / 13 categories. Docs router (`docs/README.md`) gained the mission
folder; the stale "17-document" count in `accord-app.js` corrected to 20.

Verified: native Library snapshot renders the full new tree (zero Rust
changes, manifest-driven as designed); web preview at localhost:8099 renders
the category, and The Five Adversaries opens with all fix-pass edits present.
`check-doc-links.js` clean (this file's creation closes the one open
reference from the journal).

## Homepage + mission page surfacing (v0.1092.1)

Operator: "Should we update the homepage united-humanity.us now?" Yes, and
the highest-leverage surface was the /mission page the homepage already
funnels to.

- Homepage dream screen (screen 5) now names the five: "No poverty, no
  pollution, no corruption, no fraud, no tyranny. That is the whole plan."
- /mission "Our mission" card: the five goal chips now have substance behind
  them, a line explaining they are system failures with structural antidotes,
  linking The Five Adversaries.
- /mission new card "The mission, written down": links all five mission docs
  in the Library, with the companion-docs note (humans and AI held to the
  same goodness).
- Library deep links: /library#the-five-adversaries etc. now work.
  `library-app.js` gained hash routing using the same slug convention as
  /accord (filename minus .md, underscores to hyphens); opening a doc
  updates the address bar via replaceState; hashchange navigates. Native
  needs no equivalent (no URLs; the rail navigates directly).
- Dev-aid fix found en route: `scripts/preview-server.js` had drifted from
  production nginx: its `/` mapped to web/index.html which does not exist
  (prod flattens web/pages/ into the web root, so / serves pages/index.html),
  and it had no `try_files $uri.html` equivalent, so every extensionless
  link (/library, /mission, the entire shell nav) 404ed locally. Both now
  mirrored; the full homepage -> /mission -> /library#slug click path
  verified locally with production-faithful routing.
