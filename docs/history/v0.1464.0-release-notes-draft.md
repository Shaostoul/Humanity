## Build on your own plot, with your neighbours watching

- **Building in the shared world.** On a shared server you can now build foundations, walls, windows
  and roofs on your own plot, and everyone nearby sees them go up. The server keeps every piece, so
  they are still there when you come back. You cannot build or take anything down on someone else's
  plot, and the ship's shared spaces (the Commons, First Street) are built only by people the server
  has given that rank. Nobody is told who built what.
- **If something goes wrong, you get it back.** A build the server refuses gives back exactly what it
  cost, with one plain message saying why; taking down your own piece gives its materials back (to
  your backpack, or your home's storage when the pack is full). Every build and take-down settles
  exactly once, even across a disconnect.
- **Your game keeps in step.** If a message from the server is lost on a busy connection, the game
  notices within a few seconds and fetches the right picture again.
- **Dev mode is for offline.** Dev mode's whole-ship editing now works only when you are not in a
  shared world; in one, everyone builds by the same rules.
- **People walk forward.** The ship's crew turn smoothly to face where they walk, and keep facing that
  way when they stop.
- **Coming later:** letting a household member build on your plot (the server already checks
  household permits; the page to give one is next).
