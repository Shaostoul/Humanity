# What Do These Labels Mean to You?

*A five-minute question from HumanityOS (united-humanity.us), November 2026. You do not need to
know anything about computers to answer it.*

HumanityOS is a free app with guides and tools for growing food, keeping water safe, making power
and helping each other. We are choosing the words for a small label that will sit beside messages
in the app. We have three ideas, and we cannot judge which one is clearest ourselves, because we
already know what we meant. So we are asking you.

You will see the same three messages three times, each time with different labels beside them.
For each set, please answer two questions in your own words. There are no wrong answers. If a label
confuses you, that is exactly what we need to know.

**Where your answers go:** the #feedback room on our website,
https://united-humanity.us/chat#feedback

The first time, you pick a name there (any name; it does not have to be your real one). There is
no email and no password. Please write your answers before you read anyone else's.

## Where to start

So that every set gets some fresh eyes, start with the set for the month you were born:

- January to April: start with Set A.
- May to August: start with Set B.
- September to December: start with Set C.

Then do the other two (after C, go back to A). Please do not read the end of this page first: the
part after the line at the bottom says what we meant, and reading it first spoils the question.

## What we meant

Each label says who, besides you and the person writing to you, can read the message.

- **Public** and **Everyone** mean anyone can see it, and copies of it can stay up even after you
  delete it.
- **Bluesky can read**, **Company can read** and **Not sealed** mean the service that carried the
  message keeps a copy it can read. A court can make it hand that copy over. (On Mastodon there is
  no single company: the people who run the servers can read it.)
- **Only you two**, **Private** and **Sealed** mean the message is locked on your own device before
  it leaves, so the servers in between pass it on but cannot open it. Anyone holding your unlocked
  phone or computer, or the other person's, can still read it.

We lean towards Set A, because it names who can read your message in everyday words. But what we
think is not the point of the test: if most people read a label differently from how we meant it,
the label is wrong, not the people. Your answers decide.
