# Outreach

## Purpose

These documents exist to reach people. Each one answers the same question,
"how does HumanityOS help?", for a different reader, in that reader's own
terms.

They are built as a hub and spokes: one core document that works for
anyone, plus short briefs tailored to a specific audience. The core carries
the full argument; each brief leads with its reader's situation and points
back to the core and the mission docs for depth.

## The documents

| Document | Reader | Lead with |
|---|---|---|
| `how_humanityos_helps.md` | Anyone (the core) | The whole case in one read |
| `for_individuals.md` | One regular person | Day-one value, no tech needed |
| `for_families.md` | Parents, grandparents | Skills passed down, safe screens |
| `for_public_leaders.md` | Village council to head of state | Resilience, sovereignty, zero cost |
| `for_funders_and_sponsors.md` | People with money seeking impact | The honest no-equity picture first |
| `for_affiliate_partners.md` | Store owners, makers of real goods | The planned in-game storefront, honestly |
| `what_to_expect_playing.md` | Future players | Daily life vs server-wide events |

## How to use them

Every document here is in the in-app and web Library under "How It Helps",
which means each has a shareable link, for example:

- https://united-humanity.us/library#how-humanityos-helps
- https://united-humanity.us/library#for-public-leaders

Send the link that matches the person. When in doubt, send the core doc.

They are also plain markdown files, public domain like everything else.
Copy them into an email, print them, translate them, or hand them to
someone as paper. No permission needed, ever.

## Rules these documents follow

- Truth over polish. Nothing is claimed as shipped unless it is shipped.
  The game is in active development and the docs say so.
- The money truth is stated plainly: public domain, no company, no equity,
  support is a personal gift and not tax-deductible.
- No partisan or nation-specific framing. Any leader of any community in
  any country can read their brief without feeling targeted.
- No em dashes, no hype, no manufactured urgency.

When the facts change (a feature ships, a partnership becomes real), update
the doc in the same increment, then re-run `node scripts/build-library.js`
so the Library copies stay in sync.

## Where "one more doc" stops

A new audience brief earns its place when the reader's situation, objections,
and call to action all differ from every existing brief. A new nation, a new
office, or a new age group is not a new audience; that is what the existing
briefs' plain language is for.
